4-4| O que é a string de conexão no seu codigo? 
. a gente usou a variavel string em duas ocasioes la quaundo a gente faz a conexao com o servidor 
e quando a gente faz conexão com o banco 
demonstração : private static string conexaoServidor =
    "server=localhost;user=root;password=Senac2026;";

private static string conexaoBanco =
    "server=localhost;database=ec;user=root;password=Senac2026;";

4-5 O que aparece nelas? 
. Aparece o server=localhost que é o endereço do servidor 
. user = root que no caso é o usuario 
. password = Senac2026 é a senha para entrar no banco
. e por ultimo o database=IMC nome do banco
